❓ Frequently Asked Questions (FAQ)

🤔 Will ParticleEx alter my save games or delete my progress?

No. Absolutely not. This extension only changes the visual particle system. Game saves, progress, and all in-game data remain completely untouched.

🛑 How do I uninstall ParticleEx if I want to?

Easy! If you used a .zip file, simply delete the extracted folder you placed (the folder with the exe). If you used an .exe file, uninstall it like any other program: Go to Settings > Apps > find ParticleEx and click Uninstall. ParticleEx records no permanent changes to your system and can be completely removed in seconds.

💡 The game I'm playing is already running. Do I need to restart it after installation?

Yes, to see the new particle effects, you must restart GTA 3 or Vice City if it was already open during installation. Simply load your save, and enjoy the upgraded effects.
